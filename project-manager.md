# Peroject Manager Documentation

Nama    : Niluh Anggraini
NPM     : 2313020043

Peran:
Project Manager (PM) dalam proyek pembuatan website bertugas mengatur dan mengawasi jalannya proyek agar berjalan sesuai rencana. PM merencanakan konsep dan fitur website, membagi tugas kepada anggota tim seperti frontend dan backend developer, serta memantau perkembangan pekerjaan tim. Dengan adanya PM, koordinasi tim menjadi lebih terarah sehingga proyek dapat diselesaikan dengan lebih efektif dan sesuai tujuan.
